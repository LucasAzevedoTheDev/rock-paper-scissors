This is a classic Rock Paper Scissors game and my very first project using JavaScript! It was a fundamental step in learning how to handle logic and user input in web development.

## ✨ Features
- **Player vs Computer:** Play against an automated opponent.
- **Score Tracking:** Keeps track of wins and losses during the session.
- **Interactive Console/UI:** Dynamic feedback based on game results.

## 🛠️ Key Learnings
Building this project helped me master the basics of programming:
- **Variables & Constants:** Storing game states and scores.
- **Functions & Nesting:** Organizing code into reusable blocks.
- **Conditional Logic:** Using `if/else` statements to determine the winner.
- **Randomization:** Using `Math.random()` for the computer's choice.

## 🚀 How to run locally
1. Clone this repository: 
   `git clone https://github.com/LucasAzevedoTheDev/rock-paper-scissors.git`
2. Open `index.html` in your browser.
